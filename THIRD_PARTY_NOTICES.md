# Third-party notices

The extension bundles icon data from Iconify npm packages. Iconify aggregates the
sets; each set retains its own upstream license. Original source URLs, authors,
and license metadata are included in `licenses.json` in the extension directory.
Full upstream notices are included in `notices/` and copied into both builds.

Their full notices are copied from installed npm packages into each build.

assets scraped from those services. The small Icons8 Flat Color Icons pack is
the explicitly MIT-offered open-source pack.
